
# Better-Brighter

A machine learning-based system designed to help electricity utility data quality officers identify unusual electricity records and detect potential data quality issues.

## 1. Problem Statement

Electricity utility organisations rely on accurate meter readings and customer records to support data analysis and operational decision-making. However, these records may contain missing values, duplicate entries, inconsistent information, or unusual meter readings that are difficult to identify through manual checking alone. These problems can increase the workload of data quality officers and affect the reliability of reports. Therefore, Better-Brighter aims to use a machine learning-based anomaly detection approach to identify unusual records and flag them for further investigation by authorised users.
