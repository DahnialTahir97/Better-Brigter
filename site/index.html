01 / The challenge

Small data issues can hide in large records.

Electricity utility records may contain incomplete fields, duplicate entries, invalid values or unusual meter-reading behaviour. Finding these cases manually can be time-consuming. Better-Brighter explores a structured way to surface records for further checking.

01 · COMPLETENESS

Missing information

Important fields or readings may be absent, leaving a record incomplete.

02 · VALIDITY

Invalid or inconsistent values

Values may not follow expected formats, ranges or basic data rules.

03 · PATTERNS

Unusual meter behaviour

Sudden spikes, stagnant readings or reverse movement may deserve investigation.

02 / The workflow

A two-layer approach to data checking.

The prototype combines understandable validation rules with an anomaly-detection model. The output is a review flag, not an automatic correction.

Input records

Load sample electricity utility records for analysis.

Rule validation

Check required fields, formats, duplicates and basic reading logic.

Anomaly detection

Use Isolation Forest to identify unusual numerical patterns.

Human review

Inspect flagged records and decide whether follow-up is needed.

03 / Methods

Rules first. Machine learning as support.

Each method has a different role in the prototype.

LAYER 1 · RULE-BASED

Data validation

Explicit checks help detect known issues such as missing values, duplicate records and invalid or inconsistent readings. These checks are transparent and easy to explain.

LAYER 2 · UNSUPERVISED ML

Isolation Forest

An unsupervised anomaly-detection method that identifies observations that appear different from the wider data pattern. Its output is an indication for investigation, not proof of an error.

04 / Project scope

A focused academic prototype.

The current work focuses on demonstrating validation logic and anomaly detection with sample data, supported by tests and automated checks in GitHub Actions.

ⓘ
Responsible use of results

This prototype is not connected to a live electricity utility system. It does not alter original meter readings, determine customer bills or confirm fraud. All flagged records require human review.
