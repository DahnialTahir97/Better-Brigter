Better-Brighter

Machine Learning for Anomaly Detection in Electricity Utility Records

Project overview

Better-Brighter is a proposed academic prototype to help data quality officers identify unusual electricity utility records. It combines basic data-quality checks with an anomaly-detection experiment and flags records for human review.

Problem being addressed

Utility datasets may contain missing information, duplicate entries, invalid formats or unusual meter-reading patterns. Manual checking can take time. This project explores how automated checks can help users find records that deserve closer attention.

Proposed approach

  • Use synthetic or sample records for development and demonstration.
  • Apply rule-based checks for missing fields, duplicates and invalid readings.
  • Explore Isolation Forest to flag unusual numerical readings.
  • Present flags as items for human review, not confirmed errors.

Technology

Python, pandas, scikit-learn, pytest and GitHub Actions. A web dashboard and database may be considered as future extensions.

Project documents

GitHub repository Documentation GitHub Actions

Project status

Academic prototype and portfolio work in progress. The demonstration uses synthetic data only. It does not connect to a live utility database, modify original readings or make billing decisions.
